Setup

  1. Check you have a TikTok stream keyOpen livecenter.tiktok.com/producer on a computer. You need a Server URL and a Stream key. No key? You can still stream from your phone with screen share.
  2. Create a free Oracle Cloud accountoracle.com/cloud/free. A card is asked for to verify you; the Always Free tier isn't charged.
  3. Create the serverUbuntu, shape VM.Standard.A1.Flex, 4 OCPUs, 24 GB RAM. In the Security List, open TCP 80, 443 and 3000.
  4. Run the setup command on the serverIt asks your TikTok username and the Minecraft EULA, then prints your server address and password.
    curl -fsSL https://raw.githubusercontent.com/omixz/omz./main/tiktok-live-tools/setup-vm.sh | bash
  5. Put the server address in "Server address" aboveThen open the control panel, enter the password, and paste your Server URL and Stream key.
  6. Press Go LIVE in TikTok LIVE ProducerAll three lights above turn green when everything runs.
