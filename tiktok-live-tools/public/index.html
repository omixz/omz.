Connection

The server checks about once a minute while you're offline, so you can leave it running and just start your LIVE from your phone.

☁️ Cloud streaming (hands-free mode)

Only for the 24/7 server setup (see the README). Paste the Server URL and Stream key from TikTok LIVE Producer. If TikTok gives you a new key, paste it here: the server switches to it within about 5 seconds.

Backup

Your settings are saved on the server and also backed up in this browser. Free hosts can wipe the server's disk on restart — the dashboard restores from this browser automatically.

Admin key

Set the ADMIN_KEY environment variable on your server to stop strangers from controlling your dashboard. Overlays stay viewable without it.
