# 9. Original 3D Models, Factions & Maps

Everything here is generated by code in this repo: no Blender, no store assets, no copied
models. That keeps it US$0 and 100% original IP.

## 9.1 How the models are made

`tools/sculpt/` is a small sculpting engine: shapes are written as signed-distance
functions (spheres, capsules, rounded boxes blended with smooth unions, folds, knit and
noise for cloth and skin), turned into meshes (`mesher.py`, surface nets), capped at
~12k triangles per part and written to `.glb` files with preview renders.

```
python3 tools/build_assets.py            # all packs (takes a while)
python3 tools/build_assets.py Factions   # one pack
```

| Pack | What's in it | Triangles |
|------|--------------|-----------|
| `Crew` | Mara, Tobias, Ines, Sefa: realistic adult proportions, layered clothing, faces | ~281k (4 bodies) |
| `Factions` | Harbour Watch rifleman & scout, Tidebound archer & hook | ~206k |
| `Hushed` | Drifter, Rusher, Seeker, Bellwether, Tidewalker | ~236k |
| `Weapons` | Revolver, carbine, rifle (+scope), shotgun, bow, melee | ~76k |
| `Nature` | Pines, trees, rocks, logs, bushes | ~85k |
| `Props` | Cars, crates, barrels, fences, shelves, furniture | ~105k |

Previews of every model: [`assets/previews/`](../assets/previews/).

Each body is cut into the same 15 segments as a Roblox R15 rig. At runtime `MeshKit`
measures the real joints of each character and scales/welds the segments on, so the
original animation code drives realistic bodies. If a pack is missing, the game falls back
to the built-in part models, so nothing breaks.

## 9.2 Getting the models into the game

**Option A: Open Cloud (automatic, recommended).** Create an API key (below), then:

```
ROBLOX_API_KEY=... python3 tools/upload_assets.py --user-id <your Roblox user ID>
```

It uploads the 6 packs and 44 sounds, writes the IDs into
`src/shared/Config/AssetIds.luau` and `Sounds.luau`, and rebuilds the place.

**Option B: by hand.** In Studio, File → Import 3D → pick `assets/Crew.glb` → Import.
Move the imported model into **ServerStorage → Assets** (make the folder) and name it
exactly `Crew`. Repeat for each pack. The game finds them by name.

If the imported meshes face backwards, set `YawFix = 180` in `AssetIds.luau`.

### Making an Open Cloud API key

1. Go to **create.roblox.com** → **Dashboard** → **Open Cloud** → **API Keys** → **Create API Key**.
2. Name it `aftertide-upload`.
3. **Access permissions** → add API system **Assets** → tick **Read** and **Write**.
4. **Security** → Accepted IP addresses: add `0.0.0.0/0` (any IP; uploads come from a cloud machine).
5. Set an expiration (e.g. 30 days) → **Save & Generate key** → copy it.
6. Your **user ID** is the number in your profile URL: `roblox.com/users/<this number>/profile`.

Never paste the key into a chat or commit it. Use the secure key form, or an environment variable.

## 9.3 The factions (original)

Human enemies give a second kind of fight next to the Hushed. They are our own creations,
not copies of any existing game's factions.

| | **Harbour Watch** | **The Tidebound** |
|---|---|---|
| Who | A dockside militia that holds the cannery and fuel stores with checkpoints and curfews | A Pall cult who believe the fog is a tide that "takes the unworthy" |
| Look | Patched work jackets, high-vis tabards, caps, chest rigs, gas-mask pouches | Undyed sailcloth robes, rope belts, hoods and cowls, grey ash smeared across the eyes |
| Fight | Rifles and carbines at range, flashlights at night, short radio callouts that pull nearby squads | Bows and boat hooks; close in silently, a struck **bell** calls the others |
| Units | `WatchRifleman`, `WatchScout` | `TideboundArcher`, `TideboundHook` |
| Signature sound | `Radio_Callout` (static burst) | `Bell_Strike` (hand bell) |

Encounters roll a faction about 45% of the time (`Config/Encounters.luau`), mixed with a
few Drifters. Humans collapse and stay down instead of dispersing.

## 9.4 Maps

Each crossing picks one of three hand-laid maps with its own lighting:

| Map | Setting | Light |
|-----|---------|-------|
| **Cannery Row** | Harbour streets, warehouses, piers and shallows | Bright overcast midday |
| **Larkspur Street** | Overgrown suburb, nine enterable houses, corner store | Warm golden afternoon |
| **Hollow Pines** | Hills, creek, cabins and a fire lookout | Misty morning, sun through pines |

All maps have **tall grass** (crouch in it to break line of sight; enemies have to come
close to spot you) and **short grass** scattered across verges and clearings. Night
modifiers (e.g. *Nightfall*) darken the map; every crew member carries a **flashlight**
(F) and Watch patrols carry their own, which you can see coming.

Terrain grass: in Studio select **Workspace → Terrain** and tick **Decoration** if the
grass blades don't show.
